Le jeu de bluff basé sur les notes.

Découvre ta note secrètement, discute avec les autres joueurs et essaye de trouver les Undercover.

🎮 Préparer la partie

👥 Noms des joueurs

📖 Comment jouer

1. Chaque joueur reçoit une note secrète de 1 à 10.

2. Les Villageois ont la même note.

3. Les Undercover ont une note proche, mais différente.

4. Chaque joueur regarde sa note sans la montrer.

5. Un thème apparaît. Discutez normalement du thème.

6. Après la discussion, vous votez.

7. Si tous les Undercover sont éliminés, les Villageois gagnent.

8. Si les Undercover deviennent aussi nombreux ou plus nombreux que les Villageois, ils gagnent.
